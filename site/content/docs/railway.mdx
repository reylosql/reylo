<p className="dk-subheader">Reylo Migrate on Railway</p>

Run your migrations as your service's pre-deploy command:

```json title="railway.json"
{
  "$schema": "https://railway.com/railway.schema.json",
  "deploy": {
    "preDeployCommand": ["npx reylo migrate deploy"]
  }
}
```

It runs between the build and the deploy, in a container of its own on your private network. A migration that fails stops the deploy.

## Database

Reference your Railway database's URL in your service's variables:

```sh
DATABASE_URL=${{Postgres.DATABASE_URL}}
```

## Without Node

Copy the `reylo` command into your image from Reylo's:

```dockerfile title="Dockerfile"
COPY --from=ghcr.io/reylosql/reylo:0.8.3 /usr/local/bin/reylo /usr/local/bin/reylo
```

Then run it directly:

```json title="railway.json"
{
  "$schema": "https://railway.com/railway.schema.json",
  "deploy": {
    "preDeployCommand": ["reylo migrate deploy"]
  }
}
```
