<p className="dk-subheader">Reylo Migrate on Fly.io</p>

Run your migrations as Fly's release command:

```toml title="fly.toml"
[deploy]
  release_command = "npx reylo migrate deploy"
```

It runs once per deploy, on a temporary Machine with the new image. A migration that fails stops the deploy.

## Database

The release command reads your app's secrets. Attaching a Fly Postgres database sets `DATABASE_URL`, which Reylo reads:

```terminal
$ fly postgres attach my-db
```

Any other database takes a secret of its own:

```terminal
$ fly secrets set DATABASE_URL=postgres://…
```

## Without Node

Copy the `reylo` command into your image from Reylo's:

```dockerfile title="Dockerfile"
COPY --from=ghcr.io/reylosql/reylo:0.8.3 /usr/local/bin/reylo /usr/local/bin/reylo
```

Then run it directly:

```toml title="fly.toml"
[deploy]
  release_command = "reylo migrate deploy"
```
